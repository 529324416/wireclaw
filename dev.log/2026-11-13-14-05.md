# 开发记录 2026-11-13

- 修复附件协议迁移后的类型错误，并从 `file` 模块公共出口移除 Node-only 的 `LocalFileHost`。
- 将 `session/file.ts` 重命名为 `session/attachment.ts`，同步更新源码与测试导入。
- 重构附件系统：`AttachmentFileManager`（索引、去重、校验、缓存、路径恢复）与原始 `IFileHost`（`read` / `write` / `readMeta` / `list` / `delete` / `flush` / `close`）分离。
- `AttachmentFile` 增加 `sourcePaths`；宿主元数据持久化路径组，同内容不同路径合并；字节丢失时从原始路径恢复，失败视为会话数据损坏。
- `LocalFileHost` 重写为原始 fs 宿主；新增 `OpfsFileHost`、`IndexedDbFileHost` 与 `MemoryFileHost`；client 注入本地路径读取器。
- `OpfsFileHost` 改用本地结构类型描述目录/文件/可写流，不再依赖编辑器的 OPFS DOM 类型版本。
- `Session` 改为依赖 `AttachmentFileManager`；移除位置不对的 `IFileHost.persist` / `restore`，索引通过 `host.list()` 重建。
- client 在 `/save_session` 前刷盘，退出时关闭 `AttachmentFileManager`。
- 将本地工具、MCP stdio 与传输工厂移到 `src/client`，作为 `wireclaw/client` 子路径发布；核心 `tool` 只保留 MCP 协议、客户端与 HTTP 传输。
- 核心 `McpServerConfig` 去掉传输字段；传输配置与 `ClientMcpServerConfig` 移到 `src/client/config.ts`。
- 增加 `src/browser.ts` / `src/node.ts` 与 `package.json` 子路径导出：`wireclaw` / `wireclaw/browser` 浏览器安全，`wireclaw/node` 追加 `LocalFileHost`；新增入口 smoke 测试。
- 增加 `createNewSession` 组装入口：新建空历史 Session、可选 `AttachmentFileManager` 与 `SessionRuntimeOptions`；未指定模型时由 Provider 选择默认模型（Ollama 偏好 qwen3.5:9b，DeepSeek 偏好 deepseek-flash）。
